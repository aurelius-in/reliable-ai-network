System Requirements

Minimum Requirements

Compute Resources

  • CPU: 8 cores (16 vCPUs recommended)
  • Memory: 32GB RAM (64GB recommended)
  • Storage: 500GB SSD (1TB recommended)
  • Network: 1Gbps bandwidth

Software Dependencies

  • Operating System: Ubuntu 20.04 LTS or RHEL 8+
  • Container Runtime: Docker 20.10+ or containerd
  • Orchestration: Kubernetes 1.24+ or Docker Compose
  • Database: PostgreSQL 14+ with pgvector extension
  • Cache: Redis 6.0+

External Services

  • Object Storage: Azure Blob Storage or S3-compatible
  • Key Management: Azure Key Vault or HashiCorp Vault
  • Monitoring: Prometheus, Grafana, Jaeger
  • Logging: ELK Stack or Azure Monitor

Scalability Requirements

📊 Enterprise Scale

  • High Volume: 10M+ tickets per day
  • Concurrent Users: 100K+ simultaneous users
  • Data Storage: 1PB+ total capacity
  • Availability: 99.99% uptime SLA

Cloud-Native Deployment (Recommended)

Azure Kubernetes Service (AKS)

Step 1: Infrastructure Setup

# Create resource group az group create --name rainref-prod --location eastus # Create AKS cluster az aks create \ --resource-group rainref-prod \ --name rainref-cluster \ --node-count 3 \ --node-vm-size Standard_D8s_v3 \ --enable-addons monitoring \ --generate-ssh-keys # Get credentials az aks get-credentials --resource-group rainref-prod --name rainref-cluster

Step 2: Database Setup

# Create PostgreSQL server az postgres flexible-server create \ --resource-group rainref-prod \ --name rainref-db \ --admin-user rainref \ --admin-password 'SecurePassword123!' \ --sku-name Standard_D4s_v3 \ --tier GeneralPurpose \ --public-access 0.0.0.0 \ --storage-size 1024 # Install pgvector extension az postgres flexible-server parameter set \ --resource-group rainref-prod \ --server-name rainref-db \ --name shared_preload_libraries \ --value "vector"

Step 3: Storage Setup

# Create storage account az storage account create \ --resource-group rainref-prod \ --name rainrefstorage \ --sku Standard_LRS \ --kind StorageV2 # Create containers az storage container create \ --account-name rainrefstorage \ --name knowledge-base \ --public-access off az storage container create \ --account-name rainrefstorage \ --name receipts \ --public-access off

Step 4: Deploy Application

# Create namespace kubectl create namespace rainref # Apply secrets kubectl apply -f - <<EOF apiVersion: v1 kind: Secret metadata: name: rainref-secrets namespace: rainref type: Opaque data: database-url: blob-connection-string: jwt-secret: openai-api-key: EOF # Deploy application helm repo add rainref https://charts.rainref.ai helm install rainref rainref/rainref \ --namespace rainref \ --set image.tag=latest \ --set replicaCount=3 \ --set resources.requests.memory=2Gi \ --set resources.requests.cpu=1000m

Step 5: Configure Ingress

# Install NGINX ingress controller helm repo add ingress-nginx https://kubernetes.github.io/ingress-nginx helm install ingress-nginx ingress-nginx/ingress-nginx \ --namespace ingress-nginx \ --create-namespace # Create ingress resource kubectl apply -f - <<EOF apiVersion: networking.k8s.io/v1 kind: Ingress metadata: name: rainref-ingress namespace: rainref annotations: kubernetes.io/ingress.class: nginx cert-manager.io/cluster-issuer: letsencrypt-prod nginx.ingress.kubernetes.io/ssl-redirect: "true" spec: tls: - hosts: - rainref.yourdomain.com secretName: rainref-tls rules: - host: rainref.yourdomain.com http: paths: - path: / pathType: Prefix backend: service: name: rainref-web port: number: 80 EOF

On-Premise Deployment

Docker Compose Deployment

Step 1: Prepare Environment

# Create deployment directory mkdir -p /opt/rainref cd /opt/rainref # Create environment file cat > .env <<EOF # Database Configuration POSTGRES_DB=rainref POSTGRES_USER=rainref POSTGRES_PASSWORD=SecurePassword123! POSTGRES_HOST=postgres POSTGRES_PORT=5432 # Redis Configuration REDIS_URL=redis://redis:6379/0 # Azure Blob Storage (or local MinIO) BLOB_CONNECTION_STRING=DefaultEndpointsProtocol=https;AccountName=yourstorage;AccountKey=yourkey;EndpointSuffix=core.windows.net # Application Configuration SECRET_KEY=your-secret-key-here JWT_SECRET=your-jwt-secret-here OPENAI_API_KEY=your-openai-api-key # Security ENABLE_HTTPS=true SSL_CERT_PATH=/certs/cert.pem SSL_KEY_PATH=/certs/key.pem EOF

Step 2: Create Docker Compose

cat > docker-compose.yml <<EOF version: '3.8' services: postgres: image: pgvector/pgvector:pg16 environment: POSTGRES_DB: ${POSTGRES_DB} POSTGRES_USER: ${POSTGRES_USER} POSTGRES_PASSWORD: ${POSTGRES_PASSWORD} volumes: - postgres_data:/var/lib/postgresql/data - ./init.sql:/docker-entrypoint-initdb.d/init.sql ports: - "5432:5432" restart: unless-stopped redis: image: redis:7-alpine command: redis-server --appendonly yes volumes: - redis_data:/data ports: - "6379:6379" restart: unless-stopped opa: image: openpolicyagent/opa:latest command: ["run", "--server", "/policies"] volumes: - ./policies:/policies ports: - "8181:8181" restart: unless-stopped api: image: rainref/api:latest environment: DATABASE_URL: postgresql://${POSTGRES_USER}:${POSTGRES_PASSWORD}@postgres:5432/${POSTGRES_DB} REDIS_URL: ${REDIS_URL} BLOB_CONNECTION_STRING: ${BLOB_CONNECTION_STRING} SECRET_KEY: ${SECRET_KEY} JWT_SECRET: ${JWT_SECRET} OPENAI_API_KEY: ${OPENAI_API_KEY} OPA_URL: http://opa:8181 ports: - "8080:8080" depends_on: - postgres - redis - opa restart: unless-stopped web: image: rainref/web:latest environment: VITE_API_URL: http://localhost:8080 ports: - "3000:80" depends_on: - api restart: unless-stopped nginx: image: nginx:alpine volumes: - ./nginx.conf:/etc/nginx/nginx.conf - ./certs:/certs ports: - "80:80" - "443:443" depends_on: - web restart: unless-stopped volumes: postgres_data: redis_data: EOF

Step 3: Initialize Database

# Create initialization script cat > init.sql <<EOF -- Enable pgvector extension CREATE EXTENSION IF NOT EXISTS vector; -- Create initial schema CREATE TABLE IF NOT EXISTS ref_events ( id UUID PRIMARY KEY DEFAULT gen_random_uuid(), source VARCHAR(50) NOT NULL, channel VARCHAR(50) NOT NULL, payload_json JSONB NOT NULL, user_ref VARCHAR(100), product VARCHAR(50), received_at TIMESTAMP WITH TIME ZONE DEFAULT NOW() ); -- Create indexes CREATE INDEX idx_ref_events_source ON ref_events(source); CREATE INDEX idx_ref_events_channel ON ref_events(channel); CREATE INDEX idx_ref_events_received_at ON ref_events(received_at); CREATE INDEX idx_ref_events_payload_gin ON ref_events USING GIN(payload_json); EOF # Start services docker-compose up -d # Run migrations docker-compose exec api python -m alembic upgrade head # Seed initial data docker-compose exec api python seed.py

Backup & Recovery

Automated Backup Strategy

# Database backup script #!/bin/bash BACKUP_DIR="/backups/postgres" DATE=$(date +%Y%m%d_%H%M%S) BACKUP_FILE="rainref_backup_$DATE.sql" # Create backup pg_dump -h postgres -U rainref -d rainref > "$BACKUP_DIR/$BACKUP_FILE" # Compress backup gzip "$BACKUP_DIR/$BACKUP_FILE" # Upload to cloud storage az storage blob upload \ --account-name rainrefbackups \ --container-name database-backups \ --name "$BACKUP_FILE.gz" \ --file "$BACKUP_DIR/$BACKUP_FILE.gz" # Cleanup old backups (keep 30 days) find $BACKUP_DIR -name "*.gz" -mtime +30 -delete

Disaster Recovery Procedures

# Recovery script #!/bin/bash BACKUP_FILE=$1 if [ -z "$BACKUP_FILE" ]; then echo "Usage: $0 " exit 1 fi # Download backup from cloud storage az storage blob download \ --account-name rainrefbackups \ --container-name database-backups \ --name "$BACKUP_FILE" \ --file "/tmp/$BACKUP_FILE" # Decompress backup gunzip "/tmp/$BACKUP_FILE" # Restore database psql -h postgres -U rainref -d rainref < "/tmp/${BACKUP_FILE%.gz}" # Restart services docker-compose restart api web # Verify recovery curl -f http://localhost:8080/healthz || exit 1

Troubleshooting

Common Issues

⚠️ High Memory Usage

  • Check for memory leaks in AI model loading
  • Monitor vector search query complexity
  • Review database connection pool settings
  • Consider horizontal scaling

⚠️ Slow Response Times

  • Check database query performance
  • Monitor external API response times
  • Review caching configuration
  • Optimize vector search indexes

⚠️ Authentication Failures

  • Verify JWT secret configuration
  • Check OAuth provider connectivity
  • Review token expiration settings
  • Validate API key permissions
