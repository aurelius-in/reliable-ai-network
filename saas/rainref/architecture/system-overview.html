AI Agents Architecture

RainRef employs 9 specialized AI agents, each with a specific purpose and policy controls:

1. Intake Router

Normalizes incoming support items into RefEvent format, handles PII scrubbing, and initial classification.

2. Triage Agent

Classifies intent (bug/feature/friction), assigns severity, identifies product area, and routes to appropriate playbook.

3. KB Grounder

Searches knowledge base using hybrid BM25 + vector search, composes cited answers with source references.

4. Action Planner

Analyzes tickets to suggest safe automated actions like password resets, email resends, or configuration changes.

5. Policy Gate

Deterministic policy engine that approves or blocks suggested actions based on risk assessment and business rules.

6. Executor

Executes approved actions through secure APIs, with rollback capabilities and comprehensive logging.

7. Signalizer

Converts resolved tickets into structured ProductSignals for roadmap tools and strategic planning.

8. Evaluator

Quality assurance agent that scores answer accuracy, detects knowledge drift, and flags policy violations.

9. KB Curator

Continuously improves knowledge base by suggesting new articles and updating existing content based on patterns.

Scalability & Performance

Horizontal Scaling

  • Stateless Services: All components are stateless and can be scaled horizontally
  • Load Balancing: Multiple FastAPI instances behind load balancer
  • Database Sharding: PostgreSQL read replicas and connection pooling
  • Cache Distribution: Redis cluster for distributed caching

Performance Optimizations

  • Vector Search: pgvector with HNSW indexing for sub-second similarity search
  • Query Optimization: Prepared statements and query plan caching
  • Async Processing: Celery workers for background tasks
  • CDN Integration: Static assets served via Azure CDN
