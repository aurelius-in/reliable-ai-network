API Overview

RainRef provides a comprehensive REST API for integrating with enterprise support systems. The API is built on FastAPI with automatic OpenAPI documentation, type safety, and enterprise-grade security.

🔐 Authentication

All API endpoints require authentication using one of the following methods:

  • API Key: Include X-API-Key header
  • JWT Token: Include Authorization: Bearer <token> header
  • OAuth 2.0: Include Authorization: Bearer <access_token> header

⏱️ Rate Limiting

API requests are rate limited to ensure fair usage:

  • Standard Tier: 1,000 requests/hour per API key
  • Enterprise Tier: 10,000 requests/hour per API key
  • Unlimited Tier: No rate limits

Rate limit headers are included in all responses: X-RateLimit-Limit, X-RateLimit-Remaining, X-RateLimit-Reset

🛠️ SDKs

Official SDKs are available for popular programming languages:

  • Python: pip install rainref
  • TypeScript/JavaScript: npm install @rainref/sdk
  • Go: go get github.com/rainref/go-sdk
  • Java: Available in Maven Central

Ref Events & Tickets

Core endpoints for ingesting and managing support events and tickets.

POST /ref/events
Ingest a new support event from any external system

Request Body

{ "source": "zendesk", "channel": "support", "text": "Payment processing is failing intermittently", "user_ref": "user_12345", "product": "billing", "metadata": { "ticket_id": "ZD-12345", "priority": "high", "tags": ["payment", "urgent"] } }

Response

201 Created

{ "id": "evt_abc123", "source": "zendesk", "channel": "support", "status": "received", "received_at": "2024-01-15T10:30:00Z", "processing_time_ms": 45 }
GET /ref/events
List support events with filtering and pagination

Query Parameters

Parameter Type Required Description
page integer No Page number (default: 1)
limit integer No Items per page (default: 20, max: 100)
source string No Filter by source (zendesk, intercom, github, etc.)
channel string No Filter by channel (support, issues, tickets)
status string No Filter by status (received, processing, resolved)

Response

200 OK

{ "items": [ { "id": "evt_abc123", "source": "zendesk", "channel": "support", "text": "Payment processing is failing intermittently", "status": "processing", "received_at": "2024-01-15T10:30:00Z" } ], "total": 1250, "page": 1, "limit": 20, "pages": 63 }

Error Handling

RainRef API uses standard HTTP status codes and returns detailed error information.

Error Response Format

{ "error": { "code": "VALIDATION_ERROR", "message": "Request validation failed", "details": [ { "field": "email", "message": "Invalid email format", "value": "invalid-email" } ], "request_id": "req_abc123", "timestamp": "2024-01-15T10:30:00Z" } }

Common Error Codes

Status Code Error Code Description
400 VALIDATION_ERROR Request validation failed
401 UNAUTHORIZED Authentication required
403 FORBIDDEN Insufficient permissions
404 NOT_FOUND Resource not found
429 RATE_LIMITED Rate limit exceeded
500 INTERNAL_ERROR Internal server error

Python SDK

from rainref import RainRefClient # Initialize client client = RainRefClient( api_key="your_api_key", base_url="https://api.rainref.ai" ) # Ingest a support event event = client.ref.events.create({ "source": "zendesk", "channel": "support", "text": "Payment processing is failing", "user_ref": "user_12345", "product": "billing" }) # Generate an answer answer = client.support.answer.create({ "event_id": event.id, "context": {"user_type": "premium"} }) # Execute an action action = client.action.execute({ "event_id": event.id, "action_type": "resend_activation_email", "parameters": {"user_id": "user_12345"} }) print(f"Event: {event.id}") print(f"Answer: {answer.answer_markdown}") print(f"Action: {action.status}")

TypeScript SDK

import { RainRefClient } from '@rainref/sdk'; // Initialize client const client = new RainRefClient({ apiKey: 'your_api_key', baseUrl: 'https://api.rainref.ai' }); // Ingest a support event const event = await client.ref.events.create({ source: 'zendesk', channel: 'support', text: 'Payment processing is failing', userRef: 'user_12345', product: 'billing' }); // Generate an answer const answer = await client.support.answer.create({ eventId: event.id, context: { userType: 'premium' } }); // Execute an action const action = await client.action.execute({ eventId: event.id, actionType: 'resend_activation_email', parameters: { userId: 'user_12345' } }); console.log(`Event: ${event.id}`); console.log(`Answer: ${answer.answerMarkdown}`); console.log(`Action: ${action.status}`);

Webhooks

RainRef supports webhooks for real-time notifications of important events.

Webhook Events

  • ticket.created - New support ticket received
  • answer.generated - AI answer generated
  • action.executed - Action executed successfully
  • signal.emitted - Product signal emitted
  • kb.card.approved - Knowledge base card approved
