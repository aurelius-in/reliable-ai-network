## Getting Started

### Option 1: Direct File Access
Simply open `index.html` in any modern web browser. The demo is completely self-contained and requires no server setup.

### Option 2: Local Server (Recommended)
For the best experience, serve the files through a local web server:

```bash
# Using Python 3
python -m http.server 8000

# Using Node.js (if you have http-server installed)
npx http-server

# Using PHP
php -S localhost:8000
```

Then visit `http://localhost:8000` in your browser.

### Option 3: GitHub Pages
The demo is designed to work perfectly with GitHub Pages. Simply push the `docs/demo/` folder to your repository and enable GitHub Pages in the repository settings.
