# Shipped-to-Paid Field Guide

Worksheets live on `index.html`. The Commercial Frontier Report intake is `report.html`.

## Contact note (FormSubmit)

The report form may POST a short note to `info@reliableainetwork.com` via FormSubmit ajax: name, email, phone, product, frontier, and the next-test one-liner. It does not send the full intake.

The first submission to a new FormSubmit address requires the inbox owner to confirm that address. The on-page report still generates if the POST fails or is waiting on confirmation.
